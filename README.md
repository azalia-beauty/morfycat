# Morphin · Ghost

Модульное приложение в стиле «ctOS-взлом» (Watch Dogs: глитч, сканлайны, циан и маджента на чёрном) для **Windows** и **Android**.
Один код на обе платформы. Новые функции добавляются **отдельными файлами**, обновления выходят одной командой,
а телефон сам показывает уведомление «Доступно обновление» — **даже когда компьютер выключен** (всё хранится на GitHub).

Сделано **Morphin**.

---

## 0. Быстрый старт (всё само)

1. Положите **`MORPHIN-SETUP.bat`** и ZIP с приложением в одну папку на Windows 10.
2. Двойной клик по **`MORPHIN-SETUP.bat`** (на запрос прав администратора — «Да»).
3. Скрипт сам:
   - распакует проект в `C:\Morphin\app`;
   - поставит Node.js, Git и GitHub CLI;
   - **спросит название приложения** — именно так оно будет подписано на экране Android;
   - откроет браузер для входа в GitHub (бесплатный аккаунт), создаст репозиторий и свой ключ подписи;
   - запустит облачную сборку (8–15 минут) и **скачет готовый APK** в `C:\Morphin\app\out`.
4. Перекиньте APK на телефон (например, через Telegram → «Избранное») и установите.

APK собирается в облаке GitHub, поэтому **компьютер не нужен ни для сборки, ни для обновлений**.

---

## 0.1. Новая функция от любого ИИ → обновление на телефоне

1. Откройте вкладку **«Студия»** в приложении → опишите, что нужно → **«Скопировать промт для ИИ»**
   (или возьмите `ai/AI-PROMPT.txt`) и вставьте в любой ИИ: ChatGPT, Gemini, Claude, DeepSeek…
2. **Скопируйте ответ ИИ целиком** (Ctrl+C).
3. Запустите **`UPDATE.bat`** → нажмите Enter. Скрипт возьмёт код из буфера обмена, найдёт в нём файлы,
   проверит, выпустит новую версию и дождётся сборки.
4. Телефон покажет системное уведомление «Доступно обновление» (проверка идёт в фоне раз в несколько часов,
   а при открытии приложения — сразу) → нажмите «Обновить».

Если ИИ присылает несколько файлов — пусть первой строкой каждого блока пишет `// FILE: путь/к/файлу`.
Код можно и вставить прямо в окно скрипта (правая кнопка мыши), а в конце написать `END`.
Старые версии перезаписанных файлов лежат в `.ghost-backup/`.

### Без пересборки — прямо в приложении
Вкладка **«Студия»**: вставьте ответ ИИ в поле «Ответ ИИ» → **«Проверить и установить»**. Функция появляется сразу,
данные плагинов сохраняются. Если подключить ключ ИИ (Студия → ИИ-подключение), появятся кнопки «Сгенерировать здесь».
Если плагин что-то сломал — приложение само запустится в **безопасном режиме**.

### Файлы для ИИ (`ai/`, обновляются командой `ghost.bat ai`)
`AI-PROMPT.txt` — короткая инструкция; `AI-PACK-FULL.txt` — инструкция + весь код; `AI-PACK-PART-1…N.txt` — то же кусками
для ИИ с маленьким лимитом. Все файлы — обычный текст.

## 1. Команды `ghost.bat`

| Команда | Что делает |
|---|---|
| `ghost.bat` | меню |
| `ghost.bat all` | полный автомат: установка → название → GitHub → сборка → APK на ПК |
| `ghost.bat update` (или `UPDATE.bat`) | новая функция от ИИ → выпуск обновления |
| `ghost.bat apk` | скачать последний готовый APK в `out/` |
| `ghost.bat rename` | поменять название (потом выпустить обновление) |
| `ghost.bat run` / `RUN.bat` | запустить приложение на ПК из исходников |
| `ghost.bat build` | собрать установщик Windows `.exe` локально |
| `ghost.bat release patch "что нового"` | выпустить обновление вручную |
| `ghost.bat doctor` | что установлено и настроено |

## 1.1. Ключ подписи Android

Создаётся один раз скриптом и лежит в `ANDROID-KEY-SECRETS.txt` и в `C:\Morphin\keys`. **Сохраните копию в облако или на флешку.**
Потеряете ключ — обновления поверх старой установки станут невозможны (придётся удалить приложение и поставить заново).
Файл в GitHub не попадает (он в `.gitignore`); в облако уходят только секреты репозитория.

## 1.2. Что выпускается и как обновляется

- На GitHub (**Releases**) появляются `<Имя>-<версия>.apk`, `version.json` и установщик Windows `<Имя>-Setup-<версия>.exe`.
  Если Windows-сборка упадёт, APK всё равно публикуется.
- **Android:** приложение читает `version.json`; в фоне (WorkManager) раз в 6 часов показывает уведомление, а при открытии — плашку.
  При первой установке обновления Android один раз попросит разрешить установку из этого источника; данные сохраняются,
  потому что APK всегда подписан одним ключом.
- **Windows:** при запуске приложение проверяет релиз → «Обновить» → скачивает и перезапускается новой версией.
- Хотите свой сервер вместо GitHub — впишите адрес в `updateBaseUrl` (`ghost.config.json`): туда кладутся `latest.yml` + `.exe` и `version.json` + `.apk`.

## 2. Как добавлять код (главное)

### Новая функция в интерфейсе
Создайте файл в **`src/modules/`** — он появится в меню сам. Больше ничего менять не нужно.
Образец: `src/modules/_template.js` (скопируйте, уберите `_` из имени).

```js
// src/modules/hello.js
import { panel, button, toast } from '../core/ui.js';

export default {
  id: 'hello', title: 'Привет', icon: '★', order: 100,
  // platforms: ['win'],            // если только для Windows
  mount(root, ctx) {
    root.append(panel('Привет', button('Жми', () => toast('Работает'))));
  },
};
```

### Новая функция, которой нужна система Windows (файлы, процессы, сеть)
Создайте файл в **`electron/modules/`** (расширение `.cjs`) — он подхватится сам:

```js
// electron/modules/hello.cjs
module.exports = {
  handlers: {
    'hello:ping': async (args, ctx) => ({ pong: args.text }),
  },
};
```
А из интерфейса вызовите: `await ctx.bridge.invoke('hello:ping', { text: 'hi' })`.

### Если ошибся в коде
Сломанный модуль **не роняет** приложение: он появится на странице «Модули» с текстом ошибки.
Перед выпуском запускается `npm run check` (синтаксис + форма модулей) — битый код не уйдёт в релиз.

## 4. Честные ограничения

- **Порт-сканер работает только с локальными адресами** (192.168.x.x, 10.x.x.x, 172.16–31.x.x, 127.0.0.1) — это жёстко зашито в `electron/modules/netscan.cjs`. Сканирование чужих серверов и сетей без разрешения незаконно; такое приложение не пропустят и в магазины.
- На Android доступны: тулбокс, IP/DNS/WHOIS, обновления. Терминал, мониторинг, Wi-Fi и LAN-сканер — только Windows (на телефоне нужны отдельные нативные плагины; модуль можно добавить так же файлом).
- Значок Android — стандартный; чтобы заменить, положите свои иконки в `android/app/src/main/res/mipmap-*` после `cap add android` или допишите копирование в `scripts/patch-android.mjs`.
- Подключённый ИИ работает через интернет и берёт плату/лимиты у выбранного сервиса; без него остаётся способ «копировать промт ↔ вставить ответ».
- POST-запросы к ИИ с Android идут через нативный HTTP Capacitor — на реальном телефоне это не проверялось (в тестах — имитация).
- Версия APK считается из `package.json` (`0.2.5` → versionCode `205`): минор и патч держите меньше 100.
- Потеряете ключ подписи — обновления поверх старой установки станут невозможны.
- Уведомление об обновлении в фоне приходит с задержкой (Android проверяет раз в несколько часов, на экономии батареи — реже); при открытии приложения проверка мгновенная. Сборка на GitHub не проверялась на реальном телефоне в этой среде.

## 5. Структура

```
src/
  main.js              запуск, меню, плашка обновления
  core/                ядро: ui.js, bridge.js (связь с системой), registry.js (автозагрузка), plugins.js (плагины на лету),
                       aiprompt.js (тексты для ИИ), llm.js (подключение ИИ), profile.js, store.js, updater.js
  modules/*.js         ← сюда добавляются функции интерфейса
  styles/theme.css     оформление
electron/
  main.cjs, preload.cjs   окно Windows и безопасный мост
  modules/*.cjs        ← сюда добавляются функции для Windows
android-plugin/        нативный код установки APK (копируется в проект автоматически)
scripts/               check, selftest, release, add-module, ai-pack, patch-android, setup-windows
ghost.sh / ghost.bat   всё одной командой (меню)
ai/                    текстовые файлы для ИИ (создаются `ghost.bat ai`)
.github/workflows/     облачная сборка .exe и .apk
```
